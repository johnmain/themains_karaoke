# Maintec Entertainment Brand Voice & Style Guide

## 1. Identity
- **Who:** A professional, high-energy DJ and Karaoke service run by John Main.
- **Location:** Based in Ethelbert, MB; serving the Parkland region (Dauphin, Brandon, etc.).
- **Vibe:** Experienced, reliable, community-focused, and technically superior (high-fidelity audio focus).

## 2. Voice & Tone
- **Professional yet Personable:** Use "we" or "I" (John) to maintain a local, approachable feel.
- **Authoritative:** Speak as an expert in Classic Rock, 80s, Hard Rock, Metal, and Country.
- **No Fluff:** Avoid corporate buzzwords. Use plain, punchy English that resonates with rural and small-town Manitoba clients.
- **Cultural Touchpoints:** Respectfully mention local traditions like Ukrainian Canadian socials/polka when relevant.

## 3. SEO & Technical Standards
- **Local First:** Always prioritize keywords like "Manitoba Wedding DJ," "Ethelbert Karaoke," and "Parkland Event Services."
- **Hugo Metadata:** Every page must include LocalBusiness JSON-LD schema.
- **Alt Text:** Every image description must mention the specific region or venue type (e.g., "Wedding DJ setup at a community hall in Dauphin, MB").

## 4. Coding Style
- **Comments:** Keep code comments brief and focused on "why" rather than "what."
- **Organization:** Follow standard Hugo folder structures. Keep `content/` organized by event type.
